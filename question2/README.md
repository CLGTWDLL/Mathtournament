# 第二问：无性能硬阈值的帕累托选点

当前主链不再使用 D_lim、T_lim 或 lambda_risk。候选点只保留题设物理可执行条件，然后同时比较完整任务耗时和连续后验直径上界，在无量纲帕累托前沿上选择最大下凹拐点。

## 当前结果

- 主推荐第二点：(450.000, 175.000)。
- 512个独立样本完整任务均值：209.01 s，95%区间 [204.54, 213.48] s。
- 第二点动作耗时：101.57 s。
- 有限情景最大后验直径：371.90 m。
- 连续直径证书上界：779.59 m。
- 物理保证接收：是。

另用全新2048个样本复核，均值为212.94 s。相对原融合点 (472.770,243.338) 平均快13.45 s，相对上一版高精度点 (525.326,284.265) 平均快25.11 s；两个配对95%区间均完全小于零。

精度与耗时不存在无需取舍的单一最优点。因此结果文件保留整条帕累托前沿；第三问可以根据剩余时间动态选择最快端、拐点或高精度端。

## 保留的物理约束

- 目标位于题设目标圆域内。
- 每次测向误差严格为 ±1°。
- 接收半径、5米近距离反馈、移动速度、检测、光学定位与清除耗时均按题设计算。
- 当前候选保证第二次能够接收，避免把失联方案当成正常定位方案。

这些是题目模型，不是人为设置的性能门槛。

# 无线电干扰源定位与清除

这个项目研究一个实际问题：让机器狗在测向有误差、干扰源位置未知的情况下，尽快找出并清除区域内的无线电干扰源。

## 我们怎么做

1. **先圈定位置**：把测向结果和误差变成几何约束，算出干扰源可能在哪片区域。
2. **再选检测点**：在能接收到信号的范围内，兼顾定位精度和完成任务所需的时间。
3. **边搜索边调整**：先保证目标区域被排查，再根据每次检测的反馈更新判断、调整路线并清除干扰源。
4. **处理定向干扰源**：把发射方向也纳入检查，避免只检查少数方向而漏掉目标。

## 得到了什么结果

- 定位区域的“直径”并不能保证一个同直径的圆覆盖整个区域；还需要检查最小包围圆。
- 选择第二个检测点时，距离近不一定最好，还要兼顾定位精度和完成任务的时间。
- 在论文采用的本地模拟中，多目标搜索方案完成了 21 组测试，清除了 273/273 个干扰源。
- 面对全向和定向混合的干扰源，方案在 42 组本地对照测试中清除了 546/546 个目标，平均比对照方案节省约 3000 秒。

这些结果来自所测试的本地场景，不代表在所有场景下都是最优方案。
